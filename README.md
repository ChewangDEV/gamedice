# 🎲 Dice Game

A simple two-player **Dice Game** built with HTML, CSS, and JavaScript.

Click the **Refresh** button to roll the dice for both players. The player with the higher dice value wins. If both players roll the same number, the game ends in a draw.

Link: https://chewangdev.github.io/gamedice/

## 🚀 Features

- 🎲 Random dice rolls
- 👤 Two-player gameplay
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Roll the dice with a button
- 🖼️ Dynamic dice images
- 🎨 Simple and responsive interface

## 🎮 How to Play

1. Open the game in your browser.
2. Click the **Refresh** button.
3. Player 1 and Player 2 receive a random dice value between 1 and 6.
4. The player with the higher number wins.
5. If both dice show the same number, the result is a draw.

The JavaScript generates a random number between 1 and 6 for each player and updates the corresponding dice image.
